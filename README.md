## 🚀 Featured project

### [Assignment &amp; Submission Management System](https://github.com/Sojib444/assignment-management-system)
**.NET 10 · Angular 20 · PostgreSQL · Docker · AWS**

A role-based platform where teachers author assignments, students submit work with file attachments, and teachers grade it — with deadline enforcement and per-resource ownership rules throughout. Built end to end: domain model, REST API, SPA, database, tests, containerisation and cloud deployment.

| | |
|---|---|
| **Architecture** | Clean Architecture with a compiler-enforced dependency rule; CQRS via MediatR; business invariants held in domain aggregates, not controllers |
| **Testing** | 198 automated tests — 152 unit, 46 integration against a real PostgreSQL instance, covering domain rules, handlers, validators and cross-user access control |
| **Security** | JWT (HS256), PBKDF2-HMAC-SHA256 hashing, per-resource ownership checks, RFC 7807 ProblemDetails, plus a documented threat-model review with stated limitations |
| **CI/CD** | Every push to `main` builds, runs the full suite, publishes Docker images to GHCR and deploys to a self-provisioning AWS EC2 host behind nginx |
